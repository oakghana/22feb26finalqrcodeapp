✅ MISSED CHECKOUT WARNING SYSTEM - COMPLETE IMPLEMENTATION

================================================================================
FEATURE OVERVIEW
================================================================================

Users who fail to check out before 11:59 PM will see a warning banner when they
log in the next day. The banner displays:
- Date they missed checkout
- Time they checked in
- Friendly reminder about checkout requirements
- Dismissible with X button

HOW IT WORKS
================================================================================

USER FLOW:
1. User checks in on Day 1 (5:00 PM)
2. User forgets to check out (no checkout recorded)
3. User logs in on Day 2 (next day)
4. Dashboard loads and checks yesterday's records
5. Finds unfinished attendance (check_in but no check_out)
6. Creates warning object with details
7. DashboardOverviewClient renders MissedCheckoutWarningBanner
8. User sees amber banner at top of dashboard
9. User can click X to dismiss (UI only, not persistent)
10. On next login, warning reappears (until they check out)

TECHNICAL FLOW:
page.tsx (Server) 
  → Query yesterday's records
  → Check for: check_in_time EXISTS + check_out_time IS NULL
  → Create warning object
  → Pass to DashboardOverviewClient

DashboardOverviewClient (Client)
  → Receive warning prop
  → If warning exists: render <MissedCheckoutWarningBanner />
  → Banner displays with amber styling
  → User can dismiss with X button
